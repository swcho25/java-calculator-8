# java-calculator-precourse
## 기능 목록
### 1. 입력 기능
- [ ] Console API를 통한 문자열 입력
### 2. 계산 기능
#### (1) 구분자 처리
- [ ] 구분자를 통한 문자 분리 (일반 구분자)
- [ ] 구분자를 통한 문자 분리 (커스텀 구분자)
- [ ] 일반 + 커스텀 구분자 동시 사용 가능
#### (2) 값 처리
- [ ] 추출된 문자를 양수로 변환
- [ ] 변환된 값을 계산해 반환
### 3. 출력 기능
- [ ] 계산된 결과를 문구와 함께 출력
### 4. 예외 처리 기능
#### (1) 입력 관련
- [ ] 입력 요청 시 값이 입력되지 않은 경우
- [ ] 입력된 문자열에 구분자가 존재하지 않는 경우
- [ ] 입력된 문자열에 구분자만 작성된 경우
- [ ] 입력된 문자열에 구분자가 비정상적으로 입력된 경우
#### (2) 값 관련
- [ ] 구분자로 구분된 문자가 숫자가 아닌 경우
- [ ] 구분자로 구분된 문자가 양수가 아닌 경우
- [ ] 구분자로 구분된 문자가 숫자로 바뀌었을 때 오버플로우를 발생시키는 경우
